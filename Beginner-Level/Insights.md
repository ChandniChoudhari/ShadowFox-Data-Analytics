# DMart Sales Analysis – Key Insights

## Project Overview

This project analyzes DMart retail sales data using Microsoft Excel. The main objective was to understand sales performance, product categories, regional sales and customer payment preferences through an interactive dashboard.

## Key Metrics

The following figures are displayed in the dashboard screenshot with the selected filters:

| Metric | Value |
|---|---:|
| Total Sales | ₹7,68,483 |
| Total Profit | ₹1,63,139.70 |
| Total Orders | 1,500 |
| Quantity Sold | 3,881 |
| Average Order Value | ₹512.32 |
| Profit Margin | 21% |

**Selected filters:** December, Central Region, UPI and Staples & Grains.

## Dashboard Observations

1. The dashboard provides a summary of sales, profit, orders and quantity sold.
2. Monthly sales analysis helps track changes in sales over time.
3. Category-wise analysis helps compare the contribution of different product categories.
4. The top 5 products chart highlights products with higher sales.
5. Region-wise analysis helps compare sales performance across regions.
6. Payment mode analysis provides an overview of customer payment preferences.

## Tools Used

- Pivot Charts

- Excel Dashboard
